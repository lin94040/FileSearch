# 本地文件搜索工具

一个轻量、无外部依赖的本地文件检索服务，使用原生 Python 标准库开发，启动后在浏览器提供搜索界面。

只在你指定的目录内建立内存文件索引，快速检索文件名；支持打开文件所在目录并选中、使用系统默认程序双击打开文件。内置路径白名单校验，限制访问范围，兼顾局域网访问开关与端口自定义。

适合作为自用文件检索工具，也可以在局域网内，使用手机、其他电脑访问，快速查找本机资料、代码、文档。

**现有功能：**

- 在配置目录内扫描并建立内存索引
- 网页端文件名搜索
- 打开所在文件夹并选中目标文件
- 使用系统默认程序打开文件
- 可视化配置搜索目录，自带系统目录选择弹窗
- 局域网访问开关、自定义服务端口
- 安全路径校验，禁止访问目录以外文件

**特点：**

- ✅ 零第三方依赖，一份脚本直接运行
- ✅ 纯内存索引，不写入数据库
- ✅ Web UI，任意浏览器使用
- ✅ Windows 适配
- ✅ 可局域网共享检索

**运行方式：**
直接运行 boot.bat
